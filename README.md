## What I'm building now

### Knowledge Engine · personal R&D · since Jan 2026 · early-stage

Infrastructure that turns unstructured information into structured, connected knowledge that AI agents can reason over.

- **Modular Python architecture:** every component has its own tests and must pass them before each commit
- **Reliability first:** deterministic logic where results must be exact, LLMs only where interpretation adds value
- **Safety by design:** safeguards against prompt injection from the first version
- **AI-augmented development:** built with Claude as coding assistant, while architecture and validation decisions stay with me

The code is private. Happy to talk about the engineering approach.

## How I work

- Use the model where interpretation adds value, keep deterministic logic where it must be exact, keep a human in the loop where the stakes are high.
- Constrain outputs to structured formats, validate everything, measure cost per run.
